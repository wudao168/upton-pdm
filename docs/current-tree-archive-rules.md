# 当前结构存档规则

2026-10-19 经用户确认，存档以保存工程成果和重新获取后正常打开为目标。

- 管理范围为当前设计树及关联工程图。真实组件的目录位置不限制存档；跨项目身份与覆盖冲突仍按实际图档身份检查。
- 只新增工程图时，允许引用只读模型。引用模型的未保存标记仅作集中提醒，保留内存状态、模型文件与原有版本，不自动获取模型编辑权限。
- 批次待保存检查只覆盖本次提交文件。确实选择提交的模型仍先统一保存，文件缺失、保存失败、错误配置及错误版本不能报告存档成功。
- 操作窗口确认范围后自动保存其中的待保存文件；常规提交不重复弹出保存及范围确认。准备阶段确实扩大提交范围时才额外确认。
- 原生清单中的历史路径、STEP导入记录和树外条目用于诊断，不作为当前结构的额外准入条件。当前树内实际文件缺失仍需处理。
- 嵌入式虚拟组件及已确认原生保存归属的导入组件随父装配保存，完整显示层级，不要求独立登记或升版。
- 属性索引读取异常不阻止原生图档保存；保留能读取的索引和已有值，结果集中提示后续维护。缺失的实际引用配置仍需处理。
- 未变化文件沿用现有版本；只提交新增、实际变化的图档和确有变化的引用关系。存档不强制全套重建或将无关图档升级到最新版本。
- 子件修改仅管理该子件及实际修改的工程图，不自动获取或升版上层装配。父装配自身的零件数量、引用配置、装配关系或文件内容有变化时才存档升版。
- 当前工作结构和“打开最新”跟随已存档的子件版本；历史版本和已发布快照保持原有版本组合。父装配版本不变、子件版本变化时，最新预览使用新的完整缓存目录，不覆盖已经打开的只读副本。
- 获取子件编辑权限时，已打开的上层装配可作为只读上下文一同切换工作副本，权限仍仅针对所选图档。实际未保存的可编辑内容保留并提示先保存；只读窗口的待保存状态在切换前生成恢复副本。
- 整套存档逐个读取未打开的图档，完成读取和上传副本准备后立即关闭本次临时窗口；不整批打开所有工程图，用户原有窗口保持原状。
- 上传副本、引用快照、版本冲突保护、整批提交及幂等重试继续生效，防止覆盖、漏存和重复升版。失败保留本地文件和编辑状态。

验收覆盖：连续新增工程图、参考模型存在未保存标记、只读模型出图、增量存档、跨目录引用、虚拟组件、属性读取异常、失败重试、重复存档及重新获取打开。开发机隔离验证与服务端发布不等于实际业务客户端验收完成。

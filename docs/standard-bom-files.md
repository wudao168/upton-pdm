# 标准物料图纸版本与标准件BOM资料规则

- 2D图纸、3D模型分别维护，上传成功自动生成递增版本，上传不切换启用版本。标准化人员通过标准库维护权限选择启用版本，可以重新启用旧版；版本编号仍从历史最大值递增。
- 2D、3D原文件和版本记录禁止删除、覆盖。现存3D文件按原上传顺序补编号，首次启用由标准化人员明确选择。
- 料品明细按“2D图纸、3D、资料”顺序展示附件；2D在详情页直接上传，并显示图纸版本及启用状态，可打开版本管理选择启用版本。
- 项目选用标准物料时记录当时启用的2D、3D及通用资料，后续库更新由工程师在工作BOM中明确采用。相同项目/子项目、相同物料编码共用资料引用，不依赖可重建的BOM行编号。
- 工程师有项目标准件BOM维护权限时可上传配图、技术协议、说明书、其他附件，无需审批，不写回标准物料。移除仅影响当前项目资料，原文件及历史引用保留。
- 标准件BOM合并显示“图纸附件”一列，点击后按列表查看2D图纸、3D模型、技术协议等文件及版本；标准物料库仍独立显示2D和3D。资料状态继续只按原物料完整性规则计算，信息提示使用无外框文字入口。
- 备料“列设置”可勾选“图纸附件”，采购按项目和采购件编码只读查看、预览、下载对应已发布BOM的文件；同料号多行或多采购批次保留去重后的文件清单，不查询当前工作BOM或标准库最新版，也不提供附件维护入口。
- 创建发布快照时固定文件标识、文件版本、名称、长度及SHA-256。查看历史BOM不查询最新版；早期未记录附件的历史版本保持为空，不推测补写。
- 发布资料包保留文件索引，并收录PDF、STEP和通用附件。沿用既有生产发布规则，SolidWorks源文件和DWG保留于原文件库，通过BOM下载，不混入生产发布资料包。预览补齐不得删除或覆盖标准件附件。

## 官方依据与UPLM差异

SOLIDWORKS PDM保留文件版本及修订历史，支持手动递增修订：[Versions and Revisions](https://help.solidworks.com/2026/English/EnterprisePDM/FileExplorer/c_Versions_and_Revisions.htm)。
PDM可按当时引用版本或最新版本查看BOM：[Computing BOMs for As-built Assemblies](https://help.solidworks.com/2026/english/EnterprisePDM/fileexplorer/t_Computing_BOMs_for_As-built_Assemblies.htm?id=0.7.10.3)。
UPLM按用户确认采用“自动编号、手动启用、附件免审批、已发布BOM冻结”，属于自定义业务机制，不等同于PDM原生修订审批流程。

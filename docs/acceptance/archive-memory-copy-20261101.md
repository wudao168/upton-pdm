## 官方依据与实现差异

SOLIDWORKS PDM官方[检入说明](https://help.solidworks.com/2024/english/EnterprisePDM/FileExplorer/r_File_Check_In_Dialog_Box.htm?id=0.3.0.2)及[警告规则](https://help.solidworks.com/2024/english/EnterprisePDM/admin/IDD_GROUP_WARNING.htm)说明按选取文件检入、遵守编辑权限、部分引用警告可配置。自动生成当前内存提交副本是本次用户确认的UPLM便利机制，不冒称为PDM内部实现。

原生[SaveAs3](https://help.solidworks.com/2021/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDocExtension~SaveAs3.html)以Silent|Copy生成同名副本，不使用SaveReferenced或IncludeVirtualSubAsmComps递归写源文件。后者官方定义为保存虚拟子装配中的普通组件，不是保存嵌入数据本身。选择列表通过SuspendSelectionList/ResumeSelectionList临时隔离并恢复，避免只导出选中实体；工作目录也恢复原值。

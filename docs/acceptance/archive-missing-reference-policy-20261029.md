# 缺失引用默认提示与确认勾选范围

用户已明确要求：“哪怕缺失也应该在最开始提醒且按选取范围完成存档，按pdm一样可配置，默认不阻止”。该要求覆盖此前对未勾选缺失组件统一阻止整套存档的策略。

PDM 官方依据：[检入对话框](https://help.solidworks.com/2025/english/EnterprisePDM/FileExplorer/r_File_Check_In_Dialog_Box.htm?id=0.3.0.2)分别定义检入勾选与引用警告；File not Found 等警告是否阻止检入由配置决定。UPLM 的默认值和中文组合提示按本次用户要求实现，不宣称是 PDM 的默认配置。

本次行为：

- 初次读取组件结构时发现缺失即在存档窗口提示，同一路径重复实例不重复刷屏，无额外确认弹窗。
- 插件设置增加“引用缺失时阻止存档（默认关闭，仅提示）”。旧设置没有该字段时使用不阻止的默认值；保存后保留用户选择。
- 确认勾选后，缺失但未勾选的引用保留为版本提示，不创建文件、图档编号或虚构版本，不自动扩大上传范围。
- 未勾选且未入库或另有本地修改的依赖不自动上传；已有有效存档身份的未修改引用仍保留真实版本绑定和原有校验。
- 缺失提示、原路径和结构待补全状态随所提交文件的版本快照保存，避免将“选中文件已入库”表述为“全部依赖已补齐”。原生文件中的设计关联不被删除或改名。
- 启用阻止选项时，在确认范围后、深度读取及上传准备前拒绝选中图档中的缺失引用；无关未勾选结构不参与该阻止判断。
- 选中文件本身不存在、无法读取或为空，以及编辑权限、身份、并发内容变化、真实上传和提交失败仍不能报告成功。
- 确认勾选后不再使用 Pack and Go 的 IncludeDrawings 全目录搜索；工程图读取按已确认清单进行。原生压缩组件范围与必要版本校验保留。

验证采用隔离文件、模拟 COM 和模拟 HTTP，包括三项缺失引用贯穿恢复、原生范围、依赖预检、上传及整批提交的真实程序路径；验证只上传勾选文件、提示进入提交快照、严格模式提前拒绝、设置实际传递，以及未勾选新文件不混入快照身份。没有执行用户已停止的真实 CAD 自动测试，没有改动真实样本图纸。

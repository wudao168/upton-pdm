# PC-07 转图失败修复与日志上传（2026-10-27）

## 已确认的原因

用户提供的记录包含 25 个批次、145 条文件失败，全部在打开源图档前被“本机已有 SolidWorks 会话”拦截。
1.2.0 转换程序枚举整台电脑上的 SLDWORKS 进程，只要存在任何一个就拒绝 COM 启动；因此反复提交不同图纸也不能恢复。
旧代理强制停止转换工作进程时，没有保证其启动的 SolidWorks 同时回收，可能留下阻塞后续任务的残留进程。
现有历史未记录被拦截进程的身份，不能据此断言原进程具体由谁启动。用户已明确 PC-07 是专用转图电脑，不用于人工设计，并授权自动关闭阻塞进程。

## 1.2.2 的行为

- 转换程序显式启动专用 SolidWorks，再通过运行对象表按 PID 连接，同时校验进程身份。机器上其他会话不再成为一律拒绝转图的理由。
- 专用进程归入本工作进程持有的 Windows 作业对象，工作进程被终止时自动回收其新建进程；普通模式保留对已有窗口和用户接管会话的保护。
- 启用专用转图机模式时，在重建会话前记录并回收现有残留 SolidWorks。正常连续请求复用已持有的会话，不逐次重启。
- 代理程序默认不启用整机回收；本次完整安装器明确显示并默认勾选专用转图机选项，升级会同步原安装配置和已保存用户设置。原服务器、端口、令牌与工作目录保留，失败恢复备份。
- 代理使用现有客户端诊断组件自动脱敏、分片、压缩、重试和校验回执。通过已登记的代理令牌上传，不保存管理员登录密码。新登记绑定公司，旧登记沿用系统默认公司。
- 首次运行新版会将近七天处理历史加入待传日志；技术异常、批次、请求、图档及进程信息进入集中诊断。“客户端日志”新增“转图代理”筛选。

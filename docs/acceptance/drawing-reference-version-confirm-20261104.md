# 工程图引用版本确认后误拦截修复（2026-11-04）

## 问题与原因

本机 2026.11.04.160000，P700016-6 的“标签机钣金.SLDDRW”打开失败。诊断日志显示：首次清单请求因同一零件存在 W3/W1 两条快照记录返回 400；用户选择“是”后第二次请求返回 200、43 份文件、1 条“已统一使用最新受控版本 W3”提示。随后 `TryOpenDrawingInLoadedContextAsync` 将全部 Warnings 当成未解决引用，因而再次报错。选择“否”则重新抛出原异常，被显示为失败。

这次修复处理确认结果传递和提示分类，不改写服务器历史快照，不自动改选其他引用版本，不改动存档规则。

只读数据库核对确认：工程图 W3 直接引用零件 W3，旧根总装 W1 的两条结构记录仍引用该零件 W1。捕获证据在 `tmp/drawing-version-confirm-20261104/real-snapshot-audit.json`；查询事务只读并已回滚，无业务数据写入。

## PDM 对照与采用方式

- 官方 [Get Dialog Box](https://help.solidworks.com/2021/english/EnterprisePDM/fileexplorer/r_Get_Dialog_Box.htm) 区分 Referenced Version（父文件所用引用版本）与 Latest Version（最新引用版本）。
- 官方 [Getting a Version](https://help.solidworks.com/2025/english/EnterprisePDM/ItemExplorer/t_Get_Version.htm?id=1600d2b6a46541cb9dd1c6fc1587fdc5) 允许显式选择上述两种引用版本方式。
- UPLM 的同一请求确认标记、服务器清单和已加载模型复用是本项目实现，不将它们表述为 PDM 原生内部机制。本次沿用现有明确确认使用最新受控引用的流程。

## 修改范围

1. 仅在用户选择“是”、服务器重新生成清单成功后，设置本次请求的内存确认标记。标记不进入 JSON 清单或缓存。
2. 仅将与返回文件名称及版本一致的“多个版本已统一使用最新受控版本”提示视为已处理；保留原提示和日志。其他提示仍拦截。
3. 文件版本、绑定、配置、实际字节、全部图纸视图来源检查保持原有流程。原零件、总装窗口不关闭，不替换模型。
4. “否”正常结束本次打开，不重复报错、不继续下载、不操作文件或编辑权限。对话框标题改为“确认打开引用版本”，兼顾零件和工程图。

仅修改 3 个产品源码：`PdmAddin.cs`、`PdmAddin.DrawingOpen.cs`、`PdmApiClient.cs`。使用已部署 160000 的 184 份源码与 3 个原嵌入资源冻结构建，避免带入其他任务的改动。

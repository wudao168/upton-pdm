## PDM对照及实施边界

[PDM Copy Tree官方说明](https://help.solidworks.com/2022/english/EnterprisePDM/FileExplorer/t_Copying_a_File_with_References.htm?id=0941ba88632f40a6a23bec1de647210c)说明复制父文件及所选引用可建立独立实例、新版本历史，并记录关联的新相对位置；[普通检入](https://help.solidworks.com/2023/english/enterprisepdm/fileexplorer/r_File_Check_In_Dialog_Box.htm)保留受控引用，库外引用并不因检入父文件自动入库。

本次UPLM在已有库外存档流程内采用独立导入规则，没有新增Copy Tree菜单，也没有删除几何、配置、智能关联或改变原文件名。具体修改：

- 本机库外成功回执以“原路径+目标项目”区分，旧的通用登记保留作来源参考，原文件不因此成为受控工作副本。
- 选定项目后恢复该项目的图档和基准版本；切换项目不携带旧项目编号、检出或审核状态。既有源路径副本再次提交不重复建档。
- 读取得到的辅助STEP等Other类型外部依赖随父图档收集；修正前置读取、范围判断与登记核对之间的不一致。普通未勾选3D设计修改继续按原选择处理。
- 新依赖不继承旧项目图档编号；目标项目已存在同名且字节匹配的资源只复用原版本，不检出或升版。同名不同内容仍提示核对，不自动覆盖、改名。
- 原本真实位于其他项目工作区的受控文件仍受归属保护，不直接转移。源目录回执恢复、历史补齐的项目判断与新规则保持一致。
- 原生归档字节及内部设计关联保留，工作区引用定位仍使用既有ControlledReferenceMaterializer，在下载副本上将来源指向当前清单。真正缺失且未选中的来源继续按已批准的提示策略处理，此类档案不宣称所有依赖均完整。

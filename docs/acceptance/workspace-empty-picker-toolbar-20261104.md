# 空白项目选择与工作区工具栏调整

日期：2026-11-04。插件版本：`2026.11.04.113000`。

## 原因与改动

103000版的内嵌选择区在创建时取得一次项目快照。若用户先打开选择区、服务器随后返回项目清单，只有外层选择器收到更新，已打开的主项目和图档归属列表仍保留空数据。旧版已在相同顺序下复现失败；此前回归只覆盖项目已加载后再浏览的顺序。

现在项目清单返回时同步更新当前内嵌选择区，保留搜索词和有效选择，不需要关闭重开或增加弹窗。

同时按用户要求调整：

- 删除“项目工作区”、原操作指引以及选择区内“先选择主项目……”说明。
- 顶部改为“项目搜索框、选择项目、打开最新”一行，打开最新位于选择项目右侧。
- 移除工作区“获取编辑”工具栏按钮；现有权限判断和其他编辑入口保持原有逻辑。
- 搜索始终只针对主项目和图档归属。选完项目后输入搜索仍进入项目选择，不筛选或修改图档结构。
- 沿用现有项目API、搜索匹配、图档归属及存档确认规则；产品只修改 `ProjectBrowserControl.cs`、`ProjectDocumentsControl.cs`。

与 [PDM Add-in Options](https://help.solidworks.com/2020/english/EnterprisePDM/fileexplorer/solidworks_add-in_options.htm) 的数据库信息展示及树更新原则对照，本次仅修复UPLM自定义项目选择界面的数据刷新和布局，未将该项目层级界面表述为PDM原生功能。

## 验证

- 连同已有项目浏览、归属确认、工作区、2D显示、编辑恢复和引用保护，合计469项检查通过。
- 178份源码与候选PDB一致，已有三个嵌入资源保持一致；已核对440与300像素宽截图。
- 本机三处插件、后台心跳、API及同步界面清单以 `tmp/workspace-empty-picker-20261104/final-verification.json` 为交付证据。原图、工作区与上次批准恢复后文件按发布前快照核对。

# 转图代理前台界面验收

版本：1.2.0。2026-10-24 按用户确认的三页参考图实施。

- 代理本身为 Windows GUI 程序，启动显示主窗口；支持任务栏最小化、托盘收起及双击恢复，不再依赖独立的安装管理窗口显示状态。
- 首页显示今日批次统计、当前批次/图档/阶段/进度及实时日志；逐文件完成事件实时更新成功、失败数。暂停仅拒绝新请求，已经接收的任务继续完成；退出前完成已接收任务。
- 处理记录按每个通过身份校验且被接收的 POST 转图请求计一批，文件结果属于批次，不重复累计发起次数。记录接收、开始、结束时间、来源、发起人、项目、请求标识、文件结果和日志；未提供的上下文明确显示“未提供”。失败和部分成功保留，重启后未完成记录标记中断，累计序号不因保留期限清理而重置。
- 代理设置包括连接、端口、令牌、工作目录、超时、保留天数及窗口/启动行为。已接收任务完成后应用；失败保留原设置。用户设置与历史保存在当前 Windows 用户的代理数据目录；用户设置中的令牌使用当前用户 DPAPI 保护，复制日志前脱敏。
- 安装配置保存实际解析成功的服务器地址；登录启动任务为交互式前台代理，停用旧管理窗口任务。升级脚本保留原配置、备份原任务，失败恢复原任务。用户明确要求后，已生成供其他转图服务器使用的完整 EXE 安装包，支持新装和保留配置升级。

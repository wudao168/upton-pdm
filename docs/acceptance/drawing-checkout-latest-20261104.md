## 实现

- 先独立核对图档身份、项目和原基准；只在版本落后时进入新增流程。
- 核对磁盘字节、未保存标记和未结束草稿，并在网络等待后再次复核；无法确认的修改保持原状，提示本地版本、服务器版本及另存副本的处理办法。
- 只下载所选工程图的指定最新版并核验长度与 SHA256。配套模型沿用已确认的受控工作目录；新引用尚未具备时明确提示，不扩大为下载或替换整个总装。
- 已打开工程图通过专用重载通知，在图纸关闭期间备份旧副本、安装新版并只定位该工程图的引用。准备失败尝试恢复原文件和绑定，诊断保留具体原因；未完成原生重载或实际来源核对时，不开始申请编辑权限。
- 核对所有图纸页的实际模型来源；保留既有独立副本来源记录。成功后同步当前路径的绑定与内存清单，再走原有检出、版本竞争复核及恢复记录流程。
- 完成后清理本次已成功处理的临时副本；失败时保留诊断所需的副本。未增加额外确认选项，没有自动保存原图或操作模型配置。

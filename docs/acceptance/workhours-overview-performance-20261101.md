# 完整工时、项目概览与批量人员分配性能验收

本机发布版本：V2026.11.01.210907。未生成安装包。

## 改动

- 工时项目选项、计划汇总及预算评估使用轻量项目头信息，保留公司、可见范围和岗位校验。
- 概览通过一个请求读取项目族记录，保留各项目最近 200 条审计窗口，再筛选项目备注和待办。计划、验证、关联完整性与记录独立显示。
- 分配权限仅读取目标项目。执行工程师保存返回完整权限和统计，前端更新对应项目行，取消逐行全量重载，保留部分失败重试。

## 实测

P700016 项目族共 32 个项目。API 为三次读取中位数；页面为同环境单次操作样本，存在运行波动。

| 项目 | 优化前毫秒 | 优化后毫秒 |
| --- | ---: | ---: |
| 完整工时接口 | 1543 | 27 |
| 工时汇总接口 | 1649 | 28 |
| 计划汇总接口 | 1732 | 40 |
| 预算评估接口 | 1795 | 142 |
| 概览记录接口 | 228 | 491 |
| 工时页面首次打开 | 2384 | 663 |
| 概览首次打开 | 4103 | 2468 |
| 概览刷新 | 2168 | 1050 |

三项批量保存浏览器回归：11579 → 1205 毫秒，113 → 3 次请求。PUT 响应由本地测试拦截，仅验证客户端请求及渲染开销，未修改业务人员分配；实际保存接口耗时不包含在此对比中。人员搜索每次约 47–64 毫秒，弹窗打开约 1.27 秒。

记录批量接口减少并发连接和浏览器请求，服务端按顺序处理原审计查询，因此本次记录接口自身中位耗时增加。计划已独立展示，实际概览首次打开和刷新耗时均下降。

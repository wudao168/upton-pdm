## 行为与样式

1. 存档的项目浏览页：选择已有图档项目时，在取消按钮左侧显示“确认存入已有图档项目”勾选框；勾选后才能确认选择。切换项目或取消选择后清空勾选，回车和双击与按钮共用同一门禁。空项目不增加操作。数量无法读取时不按空项目放行；项目原有提交权限继续生效。工作区浏览等非存档入口保留原操作。

# BOM 汇总数量与配置分栏验收

本机发布时间：2026-11-03，配置版本 `2026.11.03.204650`。

## 已实施规则

- BOM 工作区按汇总总数维护，数量编辑不再打开结构位置分配窗口，不按 CAD 实例均分。计件总数仍须为整数，可拆分单位保留小数规则；数量按钮仍按 1 增减。
- 人工维护的总数持久化为独立标记，保留原图档来源；刷新图档、重新归类、恢复来源属性时保留该数量。原始图档结构仅用于来源对照。
- 关联配置与套件按实际配件组合、发布状态、发布版本分栏，默认折叠。未选配的同类未发布引用汇总；不同组合分别显示。套件保留料号、名称、型号、品牌、备注等资料。
- 修改配置主料或套数时，先只读计算并列出主料、子料和配件的已存数量、目标数量，经人工确认后暂存，点击保存后生效。取消不改业务数据。固定数量沿用原规则，其他配件按用量更新。
- 确认后若相关数量、单位、选配或规则发生变化，保存拒绝过期确认并要求重新预览。数量联动保留配件原有备注、易损件等维护信息。
- 箭头使用主题色实心三角、无外框；料号居中。已发布工作修改提示待重新发布，历史发布快照保持冻结。

# 套件主料、品牌库和 BOM 附件验收

本机最终版本：V2026.11.02.125631。普通本机部署，未生成安装包。

## 行为

- 已发布且启用的料品套件可按料号、名称、型号或品牌搜索，作为关联配置主料，与普通主料共享规则及发布版本。套件仍由套件仓储管理，不复制到料品主档。
- 分类继承套件当前标准物料分类。BOM 展开的子料按套件引用 ID 合并为一条逻辑主料，以引用版本的组成数量计算整套数量，每次引用只选配一次；保留物理子料和原有权限、版本检查。
- 当前 BOM 重新读取项目附件目录，避免沿用已保存行中的旧空附件列表。历史版本及发布快照保持固定引用。弹窗丢弃旧行、旧项目或关闭后的迟到请求，刷新标准件数据时清理附件展示缓存。
- 空料号不再共用附件目录；当前列表不为此类行补入附件，界面禁止维护，接口要求先完成料号核对。原存储文件未删除。
- 料品主档工具栏新增品牌库，维护权限沿用料品维护权限。现有物料和套件品牌初始化收录，新增、编辑、批量编辑、Excel 导入及套件编辑使用库内品牌。
- 品牌改名保存曾用名称，既有物料和发布快照不批量改写；后续编辑采用规范名称。停用品牌保留历史显示，禁止用于新选择。

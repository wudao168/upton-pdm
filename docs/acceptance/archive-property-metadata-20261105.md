## 修复及PDM对照

只修改`PdmAddin.SavedDrawingArchive.cs`这一处产品文件：

- 属性读取前保留提交内容的指纹基准；内存副本使用其原文件SourceHash，不拿副本Hash与原文件混比。
- 读取后元数据有差异时，重新稳定读取源文件指纹。内容一致才继续；确实变更或不能稳定读取仍停止。
- 记录前后大小、时间和内容指纹是否一致；真实内容变更给出相应中文提示，不再仅归为属性读取失败。
- 必须完整读取自定义属性、空字段合法、只读/同名保护、原文件不改写的要求继续保留，没有恢复跳过属性的旧路径。

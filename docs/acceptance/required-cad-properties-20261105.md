## 原因和本次授权

P700017-7 的273个最新图档版本均仅有 FileName、Extension、LastWriteTimeUtc、SourceFileSha256 四项技术字段，全部标记“属性索引待补齐”。BOM取得906个实例、汇总203项，但没有分类、名称、型号等业务属性。只读核对见 `tmp/bom-properties-p7000177-20261105`。用户随后明确要求必须读取图档自定义属性，否则无法自动分类。

旧快速路径只尝试已加载文档的缓存属性，未加载、单项失败等情况下仍可提交缺少属性的版本。本次区分“已完整读取但确实没有属性”和“没有完成读取”：前者合法；后者在上传前失败并列明文件，不能再用待补齐提示冒充完成。

- [官方属性映射](https://help.solidworks.com/2020/english/EnterprisePDM/Admin/c_mapping_variables_SOLIDWORKS.htm?id=0ae05dccc1214465838f63073a0b35e1)支持文件自定义属性及配置专用属性映射到库变量。

- UPLM本次使用现有SolidWorks进程读取缓存属性；对没有加载的文件按需只读加载，装配体使用轻化选项、工程图使用出详图选项。见[官方打开选项](https://help.solidworks.com/2022/english/api/swconst/SolidWorks.Interop.swconst~SolidWorks.Interop.swconst.swOpenDocOptions_e.html?id=2.10.1.540)。这是UPLM读取实现，不声称PDM逐份使用OpenDoc6。未引入Document Manager许可配置，未更改透明加密策略。

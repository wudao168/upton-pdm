# 一期架构与边界

## 交付边界

一期包含SolidWorks插件、Windows客户端、PDM API、MySQL 8.4数据模型和项目级文件存储。网页项目管理、车间扫码、装配调试追踪、质量闭环、U9自动同步和历史全量迁移不在一期范围内。

## 关键约束

- 工作版本使用`W1/W2/...`；正式版本使用`A/B/C`。已发布A版发生变更时进入`A-W1`。
- 发布包审批固定为工艺审核和批准两级；审批完成后原子投放生产目录。
- 发布包只包含PDF、DWG、机械/电气BOM XLSX、清单、审批记录和SHA-256校验文件，不包含SolidWorks源文件。
- MySQL只保存业务数据、文件路径、大小和哈希，不保存CAD/PDF二进制。
- 项目分别绑定受控图档库与生产发包目录；存储不可用时禁止签入或发包。
- 图档引用树保留实际装配实例，包含总装、子装、零件及关联工程图；不复制FeatureManager草图、特征和配合树。

## 客户端设计系统

- 基础背景`#f4f7fb`、白色内容面板、边框`#dbe3ef`、圆角8px。
- 深蓝侧栏和标题栏，主操作蓝色，签入/通过使用绿色，异常使用橙色或红色。
- 主工作区由项目图档树、2D/3D/BOM视图和审批/发布状态组成。
- 控件字体使用Microsoft YaHei UI与Segoe UI，密度接近现有CRM。

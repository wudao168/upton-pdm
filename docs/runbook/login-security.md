# 登录安全

入口：系统设置 → 登录安全。全系统开关由内置 admin 或平台管理员修改；公司管理员可审批本公司用户的电脑、解除绑定和强制下线。所有管理操作进入全局审计。

## 开关与登录规则

- “启用同端登录限制”和“启用电脑绑定”分别控制，初始均关闭，保存后立即生效，不需重启。
- 两个开关都关闭时，电脑身份采集失败（旧格式、签名不兼容或电脑时间偏差）不拦截密码登录、自动登录和后续请求；未校验身份不登记为可审批电脑。密码、账号停用和会话撤销仍正常校验。
- 同端限制开启后，同一账号允许桌面客户端、SolidWorks 插件、网页端各一个有效会话。第二处登录被拒绝，原会话保留。同一浏览器同一站点的多标签共用会话；其他浏览器或无痕窗口使用另一会话。
- 审核浮层、嵌入预览继承所属端会话。插件打开桌面客户端时，使用同机凭证换取独立的桌面会话，不直接复用插件会话。
- 电脑绑定开启后，桌面客户端和插件共用一台获批电脑。网页采用方案 A：只限制会话数，可以在其他电脑登录，不验证 MAC。
- 主动退出释放登录名额；每分钟心跳，超过约 5 分钟无活动的会话不再占用名额。新会话取得同端名额后，原会话的旧令牌和自动登录凭证不能恢复该名额。
- 强制下线、主动退出和解绑撤销相应会话的自动登录资格。登录名额与图档业务编辑锁分别管理，下线不删除本地文件、不自动解除业务编辑锁。
- 每次由关闭切换为开启时，旧会话须重新输入账号密码；关闭开关保留电脑绑定资料和审计记录。

## 电脑绑定流程

1. 先更新目标电脑的桌面客户端和插件，再打开程序并登录一次。关闭开关时也会登记电脑，方便提前核对；开启绑定后，未批准的电脑收到中文提示，申请仍会保留。
2. 管理员核对账号、电脑名称、MAC 和登记时间，点击“确认绑定”。每个账号只允许一台获批电脑；有线和无线网卡变化不会单独改变电脑凭证。
3. 用户重新登录即可。更换电脑时先解除旧绑定，再批准新电脑。

MAC 只用于核对，身份由 Windows 保护的 RSA 设备私钥证明。客户端与插件共用当前 Windows 用户目录 `%LOCALAPPDATA%\UPLM\Device\login-identity.dat`；私钥不上传到服务器。更换 Windows 用户、重装系统或丢失该凭证后需要重新确认绑定，不能把同一电脑的所有 Windows 用户自动视作同一设备。

生产环境的策略、每个账号的电脑资料和会话保存在 MySQL `login_security_state` 表中，迁移 `182_login_security.sql` 创建该表；行锁保证多个 API 实例并发申请同一账号的名额时只允许一个成功。测试内存模式仅在当前 API 进程内保存。

## 发布与验收

发布默认保持两个开关关闭，不自动生成客户端或插件安装包。开启前必须确认目标业务客户端已更新原生程序，单独更新服务器网页不能给旧程序补上电脑凭证功能；开启限制后，缺少终端类型或原生身份凭证的旧版程序会收到中文升级提示。

核对服务器 `wwwroot`、客户端与插件的 `ui` 副本以及在线主界面和审核浮层版本；执行 `deploy/Sync-LocalUiManifest.ps1` 和 `-VerifyOnly`。开发机隔离测试、服务端发布和目标业务客户端复测分别记录；本机通过不代表 li.pw 等目标电脑已完成验收。

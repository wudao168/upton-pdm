# 钉钉 H5 员工移动办公

一期提供待办、发布及验证/验收计划审批、项目概况和计划进度、OPL、工时。入口与桌面网页使用同一个 Vue 工程和构建产物；通过 `?dingtalkOffice=1&companyId=公司ID` 打开手机布局。

## 管理员配置

1. 在 UPLM“系统设置 → 钉钉应用”保存现有企业应用的 CorpId、AppKey、AppSecret 及 PLM 访问地址。
2. 将“员工移动办公首页地址”完整填写到钉钉应用的首页及 PC 首页，保留 companyId。原“统一应用首页地址”仍是 OPL 访客提交入口，项目群中的旧卡片继续有效。
3. 在“员工账号绑定”中将当前企业的钉钉用户ID与在职 UPLM 账号一一绑定，并单独保存。用户ID从钉钉后台取得；未绑定员工打开应用时也会看到自己的用户ID。不要按姓名匹配。
4. 员工需要处于钉钉应用的可见范围内，企业应用需发布并具备现有免登所需权限。
5. 员工在钉钉工作台打开应用。数据可见范围、角色权限、账号停用、登录安全规则均由现有 UPLM 服务端校验。

员工绑定按“公司 + CorpId + 钉钉用户ID”隔离。更换 CorpId 后需要重新绑定，旧企业的同名或相同用户ID不会继承权限。绑定配置随现有钉钉设置加密保存，使用行版本防止覆盖；浏览器不接收应用密钥。

## 业务规则

- 待办读取现有审批接口和业务通知，工时催填不进入待办计数。已读事项沿用通知的已读状态。
- 发布审批、验证/验收计划审批调用现有决定接口。发布图纸预览使用该包绑定的图档版本，不替换为最新版本；无可用预览时明确提示。
- 项目只列出当前账号可读的项目；项目页签继续校验现有页签权限。
- OPL 复用网页组件及保存、完成、附件接口，沿用服务端返回的可编辑和可完成权限。手机支持卡片清单、拍照上传及原有附件上传。
- 手机工时仅保留日期、所在地、项目号、自动带出的项目名称、工时数和保存按钮；可选择过去日期补填，也可从项目带入项目号。按0.5小时填写、不填未来日期、每日合计不超过24小时、行版本和修改历史等规则继续沿用。同一日期、所在地和项目再次保存会更新对应记录，保留当日其他记录。
- 未保存工时和工时保存过程中均可直接切换模块，返回工时页保留本次页面会话中的输入；移动端工时不弹出离开前必须保存的提示。OPL和审批意见继续沿用原有切换检查，保存失败保留输入。登录凭证只保留在当前移动页面内，重新打开应用重新核验钉钉身份。

## 移动端页面维护

在“系统设置 → 钉钉应用 → 移动端页面维护”编辑当前公司的员工首页和底部导航，需要现有系统设置管理权限。该设置独立保存，不修改应用密钥、员工绑定或群内访客 OPL 页面。

1. 首页支持欢迎信息、业务概况、快捷入口、审批列表和项目列表的显示隐藏、拖拽排序及上下移动。选择模块后可调整标题、整行或半行宽度、内容列数、列表显示条数。
2. 底部导航支持名称、图标、排序和显示隐藏；首页、我的必须保留。可设置已显示页面为默认入口。主题提供绿色、蓝色、紫色，模块间距提供舒适、紧凑。
3. 中间手机预览与正式首页、导航共用组件，使用明确标注的示例数据，支持320、390、430宽度及有无项目权限预览。点击预览导航只展示选中效果，不执行真实业务。
4. 点击“保存草稿”不会影响员工。保存后点击“发布草稿 → 确认发布”，手机重新进入或在没有未保存内容时点击“刷新”后加载新布局。正在填写的工时、OPL及审批意见不会被后台发布打断。
5. 发布历史可预览及回滚，包括系统默认 V0。回滚创建新发布版本，保留当前草稿和全部历史。并发修改返回中文冲突提示并保留本页输入，重新读取前须确认放弃尚未保存的修改。

布局只能控制展示，业务接口继续校验权限。没有项目权限时，项目模块及导航不会显示；默认入口为项目时回退首页。布局加载失败继续使用当前页面已加载布局，首次打开则使用系统默认，并显示中文刷新提示。“我的”中可核对界面版本与页面布局版本。

## 网络和发布核对

公司内网 HTTP 可用；手机必须能够连接 PLM 地址，服务器须可访问钉钉接口，手机须能加载官方 JS SDK。外出使用另行配置可访问的 HTTPS 入口或 VPN。

本机部署同步服务器 wwwroot 与全部存在的客户端 ui 副本，执行 `deploy/Sync-LocalUiManifest.ps1` 及 `-VerifyOnly`，核对配置版本、主界面和审核浮层资源。无需生成客户端安装包。

## 验证

- API：`DingTalkOfficeTests` 覆盖真实钉钉接口响应的隔离模拟、绑定权限、企业隔离、普通业务授权、退出失效和配置并发；现有 DingTalk、WorkHours、OPL、UserTodo 测试继续运行。
- 前端：`dingtalkOffice.test.ts` 覆盖新旧 SDK、普通浏览器拦截和中文超时提示。
- 浏览器：`playwright.mobile-office.config.ts` 在内网 HTTP 地址运行，覆盖五个导航入口、OPL新增、工时保存及冲突保留、审批退回、未绑定和只读角色。接口和 SDK 使用隔离模拟，不代表真实钉钉手机客户端已验收。
- 真正钉钉免登和相机、相册操作仍需在已发布应用及真实安卓/iOS钉钉中验证。

官方依据：[H5免登授权码](https://open.dingtalk.com/tools/explorer/jsapi?id=11723)、[钉钉企业内部应用免登示例](https://github.com/open-dingtalk/h5app-auth-demo)。账号绑定、权限和业务状态由UPLM实现，不是钉钉原生审批流程。

# 钉钉 OPL 单机器人设置

只使用一个企业内部 H5 应用及该应用内的一个企业机器人。同一个机器人加入多个项目群，不再创建自定义 Webhook 机器人，也不再填写加签密钥或手工复制群 ID。

## 一、钉钉管理员配置一次

1. 打开已创建的企业内部 H5 应用，保留现有 CorpId、AppKey、AppSecret。
2. 为该应用启用机器人能力，设置名称，例如“PLM 问题反馈”。接收消息模式选择 **Stream 模式**，发布应用/机器人配置。
3. 复制该机器人的 RobotCode。无需另建第二个应用或第二个机器人。
4. 在应用权限中开通免登身份读取、用户姓名读取、媒体上传和机器人发送互动卡片所需权限。群通知不查询通讯录、不读取群成员，也不需要选群初始化。卡片使用内置 StandardCard，不要求自建卡片模板。
5. 应用可见范围应覆盖需要使用的人员。PLM 不校验群成员、不要求提交人有 PLM 账号，但钉钉自身的应用授权范围仍会影响能否取得姓名。

## 二、PLM 系统设置配置一次

在“系统设置 → 钉钉应用”填写：
- 启用应用、CorpId、AppKey、AppSecret、RobotCode。
- PLM访问地址：当前为 http://192.168.2.8:5173。
- 保存；约15秒后刷新，检查群登记连接状态。
- 将生成的“统一应用首页地址”原样填写到钉钉 H5 应用首页和 PC 首页，保留全部查询参数。
- 手机和电脑需能访问此内网地址；PLM服务器需能主动访问钉钉 HTTPS 和 WSS。Stream无需配置公网回调地址。

密钥加密保存且不回显；留空保留已有密钥。系统设置不管理每个项目群。

## 三、每个项目群登记和绑定

1. 在钉钉群中添加上面同一个企业机器人。
2. 在群中 **@这个机器人**，发送：登记项目群。
3. 在PLM打开对应主项目的“设置 → 钉钉群绑定”，点击“刷新群绑定”。
4. 选择自动发现的群，点击“保存群绑定”。
5. 机器人自动向该群发送“提交开口问题”入口卡片，群管理员可置顶。需要再次发送时点击“重发提交入口”。
6. 登记和绑定后即可提交问题及接收群通知，无需再次选群。已绑定项目可继续使用原群快捷入口。
7. 其他项目重复以上操作。每个群只关联一个主项目，不同群可分别绑定不同项目。子项目共用主项目的群绑定。
8. 旧的仅Webhook群记录标记为“待登记”，请按以上步骤重新登记并选择新发现的群。旧密钥不会再用于通知。

群登记命令重复发送不会生成重复群。重命名群后再次发送登记命令可更新名称。只有项目经理或管理员能修改PLM中的群绑定。

## 四、负责人来源与群通知

群内只保留现有企业机器人，不安装酷应用。提交和编辑的负责人选项来自有项目访问权限的PLM在职用户，群通知中按模板显示负责人名称。

群消息只发送到项目已绑定的群，不@负责人或全体成员。通知不再依赖姓名匹配、手机号、群成员查询和原生选群，也不提供负责人@初始化入口。

项目群请使用机器人发送的“提交开口问题”卡片，或项目设置中“群快捷入口地址”；地址必须保留`companyId`和`groupId`，从当前群打开时只列出该群已绑定项目，只有一个项目时自动选中。群名称相同不能作为关联依据；同一群的旧登记ID按真实群会话ID兼容。统一应用首页用于工作台入口，不应替代群内卡片地址。已存在的旧入口可在项目设置点击“重发提交入口”。

## 群通知模板与更新通知

“系统设置 → 钉钉应用 → 群通知消息模板”支持编辑正文、分类名称、字段顺序和换行，显示新增问题示例预览；保存配置后生效，留空或“恢复默认模板”使用默认格式。支持的字段在编辑框下方列出，未知字段或不完整括号不能保存；字段值会进行Markdown转义，不会二次替换字段值中的占位符。

默认正文每行“分类：内容”，保留所属项目、子项目、问题描述、优先级、实施状态、负责人、提交人；附件存在时列出名称。去掉正文重复标题、要求完成日期、解决措施及提交日期；这些字段仍保存在OPL中，可按需要在模板中加回。图片继续随卡片发送。

编辑问题可勾选“保存后通知钉钉群”；清单勾选“更新或完成后通知钉钉群”后，快捷完成也会通知。默认不勾选，保存成功后才发送；内容无变化不重复发送，冲突或保存失败不发送。更新/完成分别使用“OPL 问题已更新”“OPL 问题已完成”标题，默认正文的“变更内容”说明本次变化。发送失败不回滚问题，页面显示中文回执，避免重复提交。

## 五、使用流程

群成员点击入口 → 钉钉免登取得姓名 → 自动关联当前群绑定项目 → 填写完整OPL字段及图片/附件 → 保存OPL → 同一企业机器人向项目绑定群发送图文卡片。

- 支持所属项目、可选子项目、问题描述、优先级、实施状态、负责人、需求完成日期、解决措施、图片和附件。
- 仅问题描述必填，其他校验沿用OPL规则（如待确认须填写解决措施）。
- 图片上传到钉钉媒体服务后显示，支持 JPG/PNG/GIF/BMP；内网图片无需公网地址。其他附件保存在OPL，通知列出文件名。
- 提交入口只有新增能力，不提供OPL列表、修改、删除或完成操作。
- 能通过有效钉钉入口完成身份识别即可提交，不校验群成员名单或PLM账号。
- 通知失败不撤销已保存的问题，页面明确显示“问题已保存，无需重复提交”。
- 长内容按完整字段拆成多张卡片，图片在最后一张。

## 运维与验证

Stream后台自动重连。系统设置刷新可查看连接状态。配置版本冲突时刷新后重试；刷新会重新读取保存的配置，请先保存当前修改。

测试覆盖访客全部字段、姓名真实性、越权接口拒绝、群绑定、登记幂等、版本冲突、卡片图片及不触发@、不查询人员和成员、旧Webhook不再调用、通知失败保留问题、Stream心跳/应答。真实钉钉环境仍需完成机器人权限、发布、入群后验收。

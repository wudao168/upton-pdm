# 独立原生副本实机验收

仅操作工具新建并记录 PID、启动时间的 SolidWorks 实例；COM 返回已有实例时停止，绝不接管用户窗口。输出目录使用新的独立目录。源图档与模板只读复制，结束时只清理已核对身份的自有实例。

参数：`候选插件DLL 模式 新隔离目录 样本或上下文文件`。

- `workspace`：归档副本与原装配共存，核对原窗口、源文件及修改标志。
- `resources`：逐张工程图的全部图页保存、重开及版式校验，核对三类模板和源文件哈希。
- `safeguards`：真实多配置焊件和 M1 缺模型工程图在上传前停止，原窗口及原文件保持，临时副本清理。
- `httpflow`：使用隔离 HTTP 服务获取、两次存档及服务器取回。上下文含 `url/projectId/rootId`；`geometry=true` 修改实际驱动尺寸并核对实体和工程图轮廓，逐一检查非目标文件版本。仅允许回环地址与受限验收库。
- `prepare/dependencies/verify/isolate`：建立真实源副本、读取依赖、离线受控打开和独立固化验证。

`incrementalManifestScope=true` 可在已完成完整结构验证后，仅建立所选文件的增量存档范围；此模式不提交总装，也不把增量范围当作完整装配树。
